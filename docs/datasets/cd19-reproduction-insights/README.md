# CD19 computational reproduction: acquired data and integration handoff

**The data-discovery handoff is complete; full paper reproduction is not.** This package identifies and qualifies the numerical inputs and published reference outputs, acquires missing public sources, and records the precise remaining implementation and access gaps. It does not change the live application, original source library, original hypothesis, or either immutable decision in the saved investigation.

The target is Cortés-López, Schulz, Enculescu et al., *Nature Communications* 13, 5570 (2022), [DOI 10.1038/s41467-022-31818-y](https://doi.org/10.1038/s41467-022-31818-y), [PMC9500061](https://pmc.ncbi.nlm.nih.gov/articles/PMC9500061/). Acquisitions/checks span 19–20 September 2026 local time. Source-level dates and hashes are in the manifests.

## What changed relative to the existing app

**The original paper release is now qualified.** All ten supplementary files were acquired and parsed. The separate Source Data ZIP was downloaded to a new Brev directory, fully SHA-256 hashed, checked against the publisher's MD5, and CRC-tested. Its two original workbooks and mutation-effect profile PDF are retained there. The workbooks contain the experimental measurements underlying the figures; the package provides readable extractions with sheet/cell provenance. The freshly retrieved article XML exactly matches the existing pinned copy, so it was not duplicated.

**The full evaluator reference is available.** Supplementary Data 3 has 25,530 mutation–output rows: 4,255 variants × six outputs, with both replicate predictions. These are 3,599 SNVs and 656 INDELs. The 193 called variants comprise 181 SNVs and 12 INDELs, producing 351 variant–major-isoform flags. Recomputing the empirical control thresholds and applying them to the published predictions reproduces every flag. This is a successful reproduction of the call layer conditional on the published fitted values; the model fit has not been reproduced.

**The archived code was inspected beyond the compact current files.** The cited Zenodo concept DOI resolves to version 6614455, v1.0, commit `d827c59c70b67364343fe27f971bf40ef75a17d8`. The archive, all 19 reachable Git commits, binary RDS objects and historical pathnames were examined. No original softmax optimizer, saved model coefficients or complete fitting pipeline was found in the code archive/history. However, the separate Source Data workbooks release fitted/held-out values and fold numbers: matching five measured frequencies after artifact-junction merging recovers all 15,727 fitted-record barcodes and all 14,250 held-out barcode/fold assignments uniquely. This is a data-derived crosswalk: the original worksheets have no barcode column. This is recovered source output, not a new model execution. The training/CV universe discrepancy remains an explicit qualification issue. Replicate-2 skipping also has a reporting discrepancy: mean-fold Pearson r rounds to 0.92, while the printed 0.93 matches the pooled value. The other nine labels agree at two decimals. References to an absent `Mutation_effects/Softmax_modelling` directory are concrete missing-release evidence. The optional app recipe cannot be declared author-equivalent from the present evidence.

**The cryptic reference and reporter residuals are recovered.** The original association matrix yields exactly 38 mutation–isoform pairs, 36 isoforms and 31 mutations at score >0.25. The app's 30 pairs use a different, stricter rule. All 19,043 reporter rows match between GEO and Supplementary Data 1 on shared fields. Five supplementary artifact-junction columns explain all 172,395 previously unlisted counts exactly; GEO `discarded` equals the supplementary workbook's `other`. Preserve those categories and the original denominators. These findings are recorded in [input reconciliation](DATA-ACCESS.md).

**The PTBP1 evidence can move beyond a paper summary.** The Source Data measurements and existing iCLIP tracks are now parsed/qualified, with NALM-6 binding and shRNA splicing kept separate from P493-6 and MHHCALL4 siRNA, junction-qPCR and surface staining. The clinical sources are mapped at sample level. All 220 TARGET sample-runs link to 160 participants (154 primary and 66 recurrent samples); the published correlation calculation can be replayed, but participant-level independence requires a separate sensitivity analysis. Public processed/source measurements offer a numerical reproduction route even where complete raw experimental or controlled clinical data are unavailable. The detailed branch handoff identifies which layer is actually recoverable. TARGET correlations, the paired PTBP2 expression test and per-replicate surface reductions were recomputed from released measurements; The expression thresholds reproduce 80 B-ALL, 73 normal-B and 95 NALM-6 significant RBPs; qPCR Ct/well records and the 57,773-gene B-ALL/normal and 19,110-gene NALM-6 expression aggregates are supplied. The original individual-sample Gu matrices remain distinct from these public aggregates.

**A published p-value does not reproduce under its labeled test.** Source Fig. 1b contains nine matched patients. Seven increase, with a mean paired increase of 20.57 percentage points. Exact one-sided paired Wilcoxon on those released values gives **p = 0.01953125**, while the paper reports 0.009. An independent enumeration of all 512 sign assignments confirms the result. Other tests can round to 0.009; that does not identify which was used. Preserve an unresolved test-label/result discrepancy rather than forcing a match or silently substituting a test. See [independent check](DATA-ACCESS.md) and the clinical report.

**GSE197215 is substantially more usable, with explicit mapping qualifications.** All four original RDS hashes match the registry and the objects were decoded in an isolated runtime. They contain raw integer RNA counts and raw ADT measurements; the default integrated assay is unsuitable as a count matrix. The optional bead condition has entirely missing ADTs for 3,161 BE157 cells and entirely zero ADTs for 1,223 BE167 cells; these are not protein-negative biological results. GEO's 120 records are modalities and libraries, not patients. The deposited objects contain 3,345 cells under donor code 113, absent from the released 12-donor clinical map. Removing those cells gives exactly the paper's 97,981 analyzed cells; this is an arithmetic reconciliation, not an author-confirmed exclusion rule. All 12 documented donors have all four conditions, but CD139A is missing while CD139B is present. A full cell map, library map and released clinical outcome map are supplied. CAR/cell-type annotations are not present in object metadata, and product-wide comparisons must not masquerade as a qualified CAR-positive subtype analysis.

## What remains, precisely

- **Unreleased or insufficiently specified methods:** original softmax optimization code/sample weighting/solver details and custom RNA isoform-reconstruction Perl code, plus several figure/predictor intermediates. The reported fitted and held-out barcode sets are recovered; why their universes differ and how the 4,255-feature set was selected remain unresolved. These are different from missing measured count data.
- **Controlled inputs:** historical TARGET RNA and somatic-variant source material. Current public expression products and released figure tables do not grant access to controlled BAM/junction/VCF data and must not be represented as the identical frozen 2021 cohort.
- **Reader and analysis work:** ingest the acquired workbook measurements, implement provenance-preserving statistics, reconstruct the original model as far as specified, and build the donor-aware RDS adapter. Fig. 3 experimental validation releases numerical means/SD; experimental images are in the article/supplement; three separate numeric replicates must not be inferred from these summaries. No app/catalog change was made by this task.
- **Raw acquisition versus processed reproduction:** small raw PacBio files were obtained and validated. Large RNA/iCLIP transfer status is recorded separately, including any partial files and resumable acquisition scripts. Huge comparator/stimulation raw-read collections were not duplicated when decoded counts or released measured tables already support the requested numerical layer. A public URL or partial download is never labeled acquired/verified.
- **Annotation gaps:** stimulation donor 113 and technical-library discrepancies, CAR/cell-type assignments, source normalization/test-label inconsistencies, and original flow gating or other raw assay files where not released. Each has a processed alternative or a precisely bounded remaining question in the branch report. The Source Data PTBP1 knockdown table also has four labeled replicates versus the stated n=3 and stored p-value fields above 1; these require reconciliation. The source iCLIP profile totals 1,322 crosslinks versus 484 in the four plus-strand BigWig extracts, so exact pooling/provenance is not yet reproduced.

New patient recruitment, new wet-lab experiments and additional NVIDIA structures are **not prerequisites** for this study-level computational reproduction. Literature interpretation, numerical reproduction from released measurements, full raw-data pipeline reproduction and independent experimental replication are distinct achievements and must be scored separately.
