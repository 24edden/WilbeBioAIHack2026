# POG570: shared transfer deferred

The official processed-data directory exists at https://www.bcgsc.ca/downloads/POG570/ and includes expression, somatic mutation, copy-number, demographics and treatment tables.

The official README (checked 19 September 2026), https://www.bcgsc.ca/downloads/POG570/POG570_README.txt, states research-only use, handling as controlled data and no redistribution without express written permission from the POG coordinating center. No dataset files were downloaded or pushed to the shared team host in this pass. A public directory alone does not resolve permission for team redistribution.

This is now a specific access/usage blocker, not an unresolved release selection. Other public cohorts are being acquired for the team.
