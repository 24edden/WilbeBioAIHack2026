## Maynard provenance

Primary publication: Maynard et al., “Therapy-Induced Evolution of Human Lung Cancer Revealed by Single-Cell RNA Sequencing,” *Cell* 182 (2020), DOI `10.1016/j.cell.2020.07.017`, PMCID `PMC7484178`, BioProject `PRJNA591860`. Its Data and Code Availability statement names the author repository `czbiohub-sf/scell_lung_adenocarcinoma`; its README identifies `S01_datafinal.csv` and `S01_metacells.csv` as the raw matrix and metadata inputs. The publication is CC BY 4.0.

`Maynard_Table_S1_sample_metadata.xlsx` is the primary paper's Table S1, whose four sheets are “Sample Clinical Demographics,” “Sample Cell Types,” “Cancer cell annotation,” and “Sample Analyses.” It was obtained from Zenodo record 7860559, where it is called `Maynard_Supp2_Demo.xlsx`. The record's MD5 (`2500fa60aa5d4f4e3fef31f86af3b787`) equals the Cloud PMC metadata checksum for the original `mmc1.xlsx`, establishing an exact mirror rather than a transformed table. Zenodo record metadata has no explicit license; retain both the source citation and the record terms.

The expression RDS and cell-name RDS are a public processed reuse in the same Zenodo record, associated with the PERCEPTION work. They retain sample grouping but are not a substitute for the primary table's clinical metadata. The raw BioProject has 23,420 FASTQ runs and was intentionally not downloaded.

## ALK provenance and remaining constraint

The official cBioPortal study metadata says `alk_msk_2026` is 90 MSK-IMPACT cases studying acquired resistance to ALK TKIs. The saved mutation export contains ALK resistance calls including G1202R, I1171N/S, L1196M, D1203N, and V1180L. It is public portal data; cBioPortal Datahub documentation describes study staging-file downloads under ODbL, while the REST slice is retained as obtained from `https://www.cbioportal.org/api/`.

The stronger pre/post tissue table is downloaded as `ShibaIshii2022_Supplementary_Tables.pdf` from the official Springer Nature static-media URL for DOI `10.1038/s43018-022-00399-6`. Its Table S2 contains the patient identifier, primary/acquired resistance label, pre-lorlatinib ALK mutation and genotyping method where available, and post-lorlatinib mutation and method. This is public publisher material, but the article is published under an exclusive Springer Nature license; retain its citation and do not infer redistribution permission beyond use of the downloaded supplementary file.

Dagogo-Jack et al., *Clinical Cancer Research* 2019, PMCID `PMC6858956`, remains the complementary plasma study: `NIHMS1535473-supplement-1.docx` is the paired tissue-plasma table (22 paired patients) and `supplement-2.docx` contains cohort characteristics. The public PMC endpoint currently presents a browser proof-of-work download gate and the AACR page blocks the noninteractive fetch. No gate was bypassed and no controlled data were requested. The exact public primary URL remains in the manifest for an interactive download if required.
