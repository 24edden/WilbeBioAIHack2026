# CIViC September 2026 official snapshot

Original 1 September 2026 clinical evidence, variant and molecular-profile summary TSVs downloaded directly from civicdb.org. This is a CC0 knowledge base, not patient-level clinical data. MANIFEST.tsv records URLs, release date, retrieval time, row counts and SHA-256. Clinical evidence status and level must be preserved when using claims.

An earlier discovery pass found the obsolete April 2021 AWS export; those historical files, if present, are superseded by this manifest. The retired REST API returned HTTP 410 and was not used.
