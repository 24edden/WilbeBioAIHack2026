# Scientific source and instruction provenance

The `app/` scientific engine, role modules in `skills/scientific/`, contracts,
tests and deployment tooling are Team TBD source. `SOURCE-IMPORT.json` records
their imported byte hashes without private paths or runtime records. Packaging
does not change scientific decisions, prompts, models, governance or budgets.

The `skills/bionemo-boltz2/` subset retains the installed NVIDIA BioNeMo agent
toolkit 0.1.0 instructions and references, declared **Apache-2.0 AND CC-BY-4.0**.
Original instruction text and hash are preserved. License texts are available
from [Apache](https://www.apache.org/licenses/LICENSE-2.0) and
[Creative Commons](https://creativecommons.org/licenses/by/4.0/legalcode.en).
This attribution is separate from Team TBD's authored scientific instructions;
it does not claim NVIDIA inference occurred.

The OpenAI Life Sciences Databases plugin 0.1.5 declares a proprietary license.
Only its version, attribution and content hashes are included. Its instructions
and source-client code must come from an authorized private installation; see
[setup](SETUP.md). No proprietary plugin bytes are shipped here.

Public evidence retains its source URLs, original locators, hashes and scope in
the case packs. The CD19 author scripts retain their original
[`author_LICENSE.md`](casepacks/sources/cd19-discovery/author_LICENSE.md) and pinned
repository attribution in `SOURCES.json`. The released CD19 endpoint extracts
identify the source publication, supplementary workbook and CC BY 4.0 terms with
third-party exceptions. This repository makes no new licensing or scientific
validity claim over public source data. Full source articles and larger/raw input
files are external and hash checked when installed privately.

The Rosalind-informed workflow is Team TBD-authored guidance based on public
documentation. It is not a proprietary GPT-Rosalind model skill, model entitlement
or claim that GPT-Rosalind inference occurred. Provider usage retains its actual
configured and returned identity.
