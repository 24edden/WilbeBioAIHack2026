# TRACE presentation workspace

Working speaker notes and demo ideas for the five-minute Wilbe Bio x AI presentation.
The source rubric is [Context/judgingCriteria.md](../Context/judgingCriteria.md).

Three independent reviews feed the shared script:

- `ux-demo-script.md`: scientist experience, user control and usability.
- `judges-wow-script.md`: visual scenes and memorable, evidence-backed demo moments.
- `technical-demo-script.md`: technical depth and meaningful NVIDIA/OpenAI use.
- `demo-script.md`: the combined five-minute narrative and fallback sequence.
- `access-slide-script.md`: public demo URL, QR placement and audience access checks.

Every proposal must distinguish shipped behavior, implemented but unverified
integrations, and future work. Mock output, recorded playback and fresh model
inference must be named accurately in the spoken script. Presentation language
must not imply that agent agreement establishes causality or scientific validity.

This folder contains planning material, not a generated slide deck or a submission.

for exact browser checks and limitations; it supersedes the earlier deployment
status noted when the three independent reviews were drafted. Live model
integrations and the public audience URL remain unverified/unpublished.
